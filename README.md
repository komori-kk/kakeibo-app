# ハッピー家計簿 (kakeibo-app)

手取り22万円の一人暮らし向け「統合型家計管理Webアプリ」（React + Vite + Tailwind CSS）

## 主な機能
- **ウェルカム・トップページ & 4桁PINロック / 金額目隠しモード**
- **ダッシュボード（ホーム）**：
  - 「今月あといくら使えるか（総収入 - 固定費 - 貯蓄 - 今月の変動費支出）」のリアルタイム巨大表示
  - 直近7日間の利用ペース判定（週基準予算 約1.8万円との比較）
  - 3種類のインタラクティブ・グラフ（費目別ドーナツグラフ・7日間推移棒グラフ・月間収支バランス）
- **すべての収支入力（片手スマホ最適化）**：
  - 日々の支出（変動費9費目）、収入（給与・副業・臨時収入など）、固定費・先取り貯蓄のすべてを記帳可能
  - 親指テンキー＆スマホ標準キーボードの2WAY対応
- **収支明細 & バックアップ**：
  - 全収支のフィルター・インライン編集・削除・月次基本収支の一括登録
  - LocalStorage自動保存 ＋ JSONファイルの書き出し/復元バックアップ
